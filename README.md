# FL Simulator

飲食店の経営計画をシミュレーションするアプリの土台です。現在は準備中の画面のみで、計算機能は今後実装します。

## 技術構成

- Vite / React / TypeScript
- npm
- Vercel

## ローカル開発

Node.js 24.x を使用します。

```sh
npm ci
npm run dev
```

## 確認・ビルド

```sh
npm run lint
npm run build
npm run preview
```

## 公開

GitHub: https://github.com/kokorau/fl-simulator

Vercel の Git 連携で `main` ブランチを本番として公開します。
