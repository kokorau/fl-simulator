# FL Simulator

カルニータス店の構想をもとにした、飲食店の開業計画シミュレーター。

- 公開: https://fl-simulator.vercel.app
- GitHub: https://github.com/kokorau/fl-simulator
- Vite / React / TypeScript / npm / Vercel

## 開発

Node.js 24.x を使用します。

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```

`main` への push は Vercel の本番デプロイを起動します。

## 機能

- 売上・仕入れ・経費・開業資金の編集と即時計算
- 食材原価、人件費、FL率、営業利益、損益分岐客数
- 枝肉 → 可食部 → 加熱後 → 食数の歩留まり計算
- 生産上限、売れ残り、需要に対する供給不足
- 客数40・60・80・100・140人の比較
- 集客が立ち上がるまでの期間を含む12か月の資金推移
- 初期サンプルとの差額、リセット、ブラウザへの自動保存

## 初期モデル

数値は過去の会話から作った仮説で、見積もり・実測ではありません。

26日営業、客数70人/日、客単価1,600円、15席。半丸40kgを複数日に分けて使う想定で、枝肉使用量20kg/日、700円/kg、可食部62.5%、加熱歩留まり73%、提供肉130g/食。自己資金400万円、借入200万円、開業支出320万円。

初期値では販売上限70食、月商291.2万円、営業利益55.176万円、生活費など控除後の通常月資金増減17.176万円。

## 計算の定義

`src/model.ts` に計算と入力の定義を集約しています。

- 販売上限 = floor(枝肉kg × 可食部率 × 加熱歩留まり × 1,000 ÷ 提供g)
- 販売数 = min(想定客数, 販売上限)
- 原価 = 枝肉使用量全額の仕入費 + 販売人数分の副材料・ドリンク費
- 人件費 = (従業員月給 + 時給 × 延べ勤務時間 × 営業日数) × (1 + 追加負担率)
- 営業利益 = 売上 − 原価 − 人件費 − 包材・決済 − 家賃・光熱・その他 − 減価償却
- 資金増減 = 営業利益 + 減価償却 − 店主生活費 − 元本返済 − 利息 − 税金積立
- 初期資金 = 自己資金 + 借入 − 物件取得 − 内装・設備 − その他開業費

損益分岐点は仕込み量、人員、固定費を変えずに客数だけを逆算します。生産上限を超える場合は画面に表示します。集客達成率は初月から指定月まで直線的に増加し、その後一定です。仕込み量は初月から一定です。

## 範囲・制限

- 個人事業を想定。店主生活費はLに含めず資金から控除。
- 税抜・当月入出金の簡易モデル。消費税、入出金の時差、在庫残高、借入完済後の返済停止は未反映。
- 税金積立は税額自動計算ではなく利用者の設定額。
- 副産物売上、副材料の売れ残り、時間帯別ピーク、調理設備能力は未反映。
- データは `fl-simulator:v1` キーでこのブラウザにのみ保存。端末間同期やサーバー保存はありません。
